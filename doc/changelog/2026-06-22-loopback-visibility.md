# 2026-06-22 — Видимость loopback в Chrome + чистка idle

## Почему

В Chrome (и других потребителях, фильтрующих устройства по
возможностям) «FluxFrame Camera» (`/dev/video10`) не появлялась в списке
камер. Параллельно демон надолго залипал в состоянии `DeepIdle`, которое
по факту ничего не делало (ONNX не выгружался).

## Что изменилось

- **Новый `idle.min_visibility_fps` (по умолчанию `10`).** Пока демон в
  idle, placeholder стримится в loopback с частотой
  `max(idle.fps, idle.min_visibility_fps)`. Это «пульс видимости»: он
  удерживает устройство анонсирующим CAPTURE-caps, чтобы Chrome/WebRTC
  продолжали его перечислять. Частота не зависит от камеры (кадры
  статичные), поэтому не ограничена `input.fps`. Старый каденс ~1 Hz был
  слишком редким для надёжного перечисления в Chrome.

- **Кеширование placeholder.** Сконвертированные байты кадра мемоизируются
  как `Arc<[u8]>` (`FrameBuffer::Shared`), поэтому поднятый каденс не
  плодит аллокаций/конверсий на каждый тик.

- **Состояние `DeepIdle` удалено.** Это был no-op-стаб, который никогда не
  выгружал ONNX и мог оставить демон залипшим. `idle.deep_idle_secs`
  теперь принимается в TOML, но игнорируется (back-compat). Счётчик
  `deep_idle_entered_total` сохранён ради дашбордов и всегда равен `0`.
  Реальная выгрузка ONNX вынесена в отдельную задачу.

- **`fluxframe check` предупреждает про `exclusive_caps`.** Если у
  loopback-устройства нет `exclusive_caps=1`, Chrome его не покажет;
  `check` теперь это диагностирует и подсказывает команду перезагрузки
  модуля.

## Действия оператора

- Загружайте модуль с `exclusive_caps=1` (см. README → «Virtual camera»).
  Проверка: `fluxframe check`.
- При желании настройте `idle.min_visibility_fps` в `fluxframe.toml`
  (диапазон `1..=60`).

## Отложено (требует железной верификации)

Главная причина «video10 невидим, когда камера занята» — output-производитель
всё ещё сносится при каждом ретрае входа. Развязка жизненного цикла
loopback от входа (always-on producer + backoff + split input/output
bus-fatal) запланирована отдельным проходом. См. README → «Stage 15
follow-ups».
